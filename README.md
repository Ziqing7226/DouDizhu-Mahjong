# 斗地主 & 麻将 · AI 单机版

纯前端实现的棋牌合集：**斗地主**（三档难度 AI）与**四人麻将**
（吃碰杠胡、番种计分、三档难度 AI）。无需联网、无需安装依赖，
**双击 `index.html` 即可开始**。

进入页面先选择斗地主或麻将（左上角「游戏大厅」按钮可随时切换），
再选择场次（新手场 / 高手场 / 大师场）即可开局。

---

## 快速开始

```
双击 index.html          # 推荐：直接用浏览器打开
```

不需要本地服务器，所有模块用普通 `<script>` 标签加载（刻意没用 ES Module，
避免 `file://` 协议下的跨域限制）。想跑测试需要 Node（可选）：

```bash
node tests/test-core.js            # 规则引擎 + AI 逻辑回归
node tests/test-ui.js              # 无浏览器端到端（双游戏全链路）
```

## 斗地主玩法

- **选场**：开局前在大厅选择 新手场 / 高手场 / 大师场，难度即刻生效
- **叫分抢地主**：1 / 2 / 3 分，叫 3 分立即锁定，三家都不叫则重新发牌
- **加倍**：两个农民先选（加倍 ×2 / 超级加倍 ×4），地主随后决定是否反加
- **出牌**：地主先出，逆时针轮转；两家都不要则由最后出牌者重新领出
- **倍数**：叫分倍数 × 加倍 × 每个炸弹/王炸（×2）× 春天（×2）
- **计分**：地主 ±2×底分×倍数，农民 ±底分×倍数

支持的牌型（14 种）：单张、对子、三张、三带一、三带二、顺子、连对、
飞机、飞机带单、飞机带对、四带二、四带两对、炸弹、王炸。
2 和王不参与顺子 / 连对 / 飞机；同类型同长度才能比大小。

AI 三档难度：新手（出牌随意）→ 高手（记牌推算 + 残局推演 +
农民配合）→ 大师（完全信息 AI，能看到所有人手牌）。
设计细节与强度测量见 `docs/开发记录.md`。

## 麻将玩法

- **行牌**：136 张牌，四人；摸牌 → 打牌循环；别家打牌时可
  **胡 / 杠 / 碰**，下家可**吃**（优先级 胡 > 杠 > 碰 > 吃）；
  支持暗杠、加杠与抢杠胡，杠后从墙尾补牌
- **胡牌**：四组面子（顺子/刻子）+ 雀头；门清时七对、国士无双也可胡
- **番种**：平胡 1 番起，累加 自摸 / 门前清 / 碰碰胡 / 混一色 / 七对 /
  清一色 / 字一色 / 天胡 / 地胡 / 国士无双 等；
  得分 = 底分（100）× 总番数，自摸三家各付、点炮者一家付，庄家翻倍
- **自动胡**：能胡时自动和牌，无需按键
- **余牌器**：实时显示 34 种牌各剩几张未出现

## 其他功能

- **游戏大厅**：斗地主 / 麻将一键切换；局终可换场次或续战同一批对手
- **操作**：点击选牌、按住横拖连选一排牌；快捷键 Enter 出牌 / 空格不要 / H 提示；
  回合 30 秒超时自动行牌
- **移动端**：手机横屏自适应布局、信息面板抽屉、竖屏引导与全屏建议
- **语音播报**：出牌 / 叫分 / 胡牌实时播报，预录制语音包（107 条，
  标准普通话；男声座位为女声降速变调）；语音包不可用时自动退为
  语义提示音
- **记牌器 / 余牌器**：实时显示未出现的牌
- **战绩统计**：场次 / 胜率 / 连胜 / 积分，本地持久化（两游戏分开统计）
- **动画与音效**：发牌、出牌、炸弹震屏、春天横幅、胡牌锣；
  音效由 WebAudio 实时合成，不依赖任何音频文件
- **背景音乐**：纯 WebAudio 合成的中式五声音阶旋律，
  牌局紧张时自动切换紧张型旋律

## 目录结构

```
├── index.html              页面骨架（游戏大厅 + 斗地主/麻将双视图）
├── css/style.css           界面样式与动画
├── js/
│   ├── app.js              游戏模式调度
│   ├── game.js             斗地主主流程状态机
│   ├── cards.js            斗地主牌型识别 / 大小比较 / 压制组合枚举
│   ├── decompose.js        手牌拆解器（AI 评估基础）
│   ├── ai.js               斗地主三档难度 AI
│   ├── mj/                 麻将五模块（牌模型 / 规则 / AI / 渲染 / 主流程）
│   ├── ui.js               斗地主渲染层
│   ├── audio.js            WebAudio 实时合成音效
│   ├── music.js            WebAudio 合成背景音乐
│   ├── voice.js            语音播报（预录制语音包 + 语义音效兜底）
│   ├── voice/              预录制语音包（107 条 mp3）
│   ├── storage.js           战绩与偏好存档（localStorage）
│   └── mobile.js           移动端适配
├── tools/                  语音包再生成 + 麻将 AI 三难度对局自测
├── package.json            仅语音包再生成需要 npm 依赖（游玩零依赖）
└── tests/                  规则回归 + 无浏览器端到端 + AI 强度工具
```

分层原则：牌模型 / 规则 / AI 是纯逻辑，不碰 DOM；渲染层只负责画；
主流程状态机串流程。开发细节（AI 机制、强度测量、问题调研记录）
见 `docs/开发记录.md`（本地文档，不入库）。
